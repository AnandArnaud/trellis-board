# trellis-board

Trellis is a minimal single-page kanban board — add cards, move them across columns, mark them done.

**Stack:** Vite + React (TypeScript, SPA)

It is intentionally small. The user-action handlers log to the console.

## Key user actions

add card · move card · complete card

## Running it

```bash
npm install
npm run dev   # http://localhost:5173
```
